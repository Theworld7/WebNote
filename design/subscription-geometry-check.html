同一个订阅块有两套 CSS：编辑器的 .subs-*（scoped）与导出快照的 .note-sub-*（docStyle）。数值真源只有 lib/subscription-geometry.ts 一份：导出侧是模板字符串直接插值， 编辑器侧 CSS 取不到 TS 常量、保留字面量副本（与 SYSTEM_FONT_STACK ↔ --font-sans 同一惯例）。 这一页先读两侧源码逐项比对真源，再把两套 CSS 挂到真实 DOM 上量 computed， 把「改一边漏另一边」钉死。设计预览页是独立画板规格，不参与运行时几何。
